Telemetry Frame Solver

Python · Constraint solving · Tkinter

Overview

Built and shipped a constraint-solving application during my Summer 2026 software and instrumentation internship with Naval Test Wing Atlantic’s Advanced Systems Group, hired through ASRC Federal TRMCi.

Solver design

Implemented a 2D backtracking constraint-satisfaction solver with forward checking. A six-metric heuristic ranks candidate placements to pack arbitrary sensor channel sets into IRIG-106 Chapter 4 frames while satisfying competing constraints.

Application and delivery

Designed a Tkinter interface and command-line interface with input validation, unit tests, and automated color-coded Excel exports. Delivered the application solo and handed it off to the group for maintenance.

Impact

Replaced a manual 20–40 hour engineering process with an automated run. The application was adopted by three or more engineers at Naval Test Wing Atlantic Instrumentation.
