# PDR presentation

Source: `accumulator.pptx` (292 slides, including the hidden slide 86).

The browser viewer uses `slides.json` and `slide-001.webp` through `slide-292.webp`, rendered at up to 1920 pixels wide. It loads only the selected slide, supports previous/next, keyboard navigation, direct slide-number entry, and a full-size image link.

The original PowerPoint is unchanged. Browser slides are static: animations, transitions, and embedded media do not play. Replacing the PPTX requires regenerating the slide images and manifest.
