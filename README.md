# Portfolio template

A responsive portfolio built with plain HTML, CSS, and JavaScript. No build step or dependencies are required.

## Customize

- Replace `Your Name`, role, organization, location, biography, and footer in `index.html` and `projects/*.html`.
- Replace `hello@example.com` and the `example.com` social links with your contact details. These are intentional placeholders.
- Rename project titles and categories on the homepage, then fill in each matching project page. `project-six.html` is an extra page ready to link from a new card.
- Replace the image placeholders with your own images and descriptive alt text. Add your own project resources where indicated.
- Update page titles and meta descriptions before publishing.
- Adjust colors, typography, and spacing in `style.css`.

The original biography, affiliations, contact details, project write-ups, images, videos, and report have been removed from this template.

## Preview

Open `index.html` directly, or run `python3 -m http.server 8000` in this folder and visit http://localhost:8000.

## Dark mode

Every page includes a keyboard-accessible dark mode toggle. The initial theme follows the system preference; a manual choice is saved in local storage and shared across pages. If storage is unavailable, the toggle still works for the current page. Clear the `portfolio-theme` storage key to return to the system default.

## Publish

Upload `index.html`, `style.css`, `theme.js`, and the `projects` folder to any static web host, including GitHub Pages.
